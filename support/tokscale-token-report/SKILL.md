# Tokscale Token Report support

This support directory contains the report generator used by `dsh-token-overview`. The installing AI copies it to `~/.codex/skills/tokscale-token-report`. It scans local AI-client logs at runtime and writes reports under the user's DSH data directory. This repository intentionally excludes generated reports, lost-history corrections, history locks, model-price caches, credentials, and machine-specific configuration.
